# AMAS FARM Management System

A centralized digital management system for **AMAS FARM** designed to manage farm operations, business activities, financial records, inventory, employees, assets, and management reports in one system.

## Project Goal

The goal of this project is to replace scattered/manual farm records with a connected system where different farm activities are managed through specialized subsystems and their information is combined into a central reporting system.

The system will help AMAS FARM:

* Manage daily farm operations
* Manage sales and purchases
* Track expenses, cash and bank transactions
* Manage stock, feed and medication
* Manage customers and suppliers
* Manage employees and payroll
* Track farm assets
* Monitor production and mortality
* Generate financial and management reports
* Provide useful information for management analysis and decision-making

## System Structure

The system will be organized into several interconnected subsystems:

* **Farm Operations**
* **Sales & Business**
* **Finance**
* **Inventory**
* **Human Resources & Administration**
* **Asset Management**
* **Central Reporting & Management**

Each subsystem will manage its own activities while sharing relevant information with the centralized system.

## Technology

The technology stack will be finalized during the system design phase.

The current development direction includes:

* **Backend:** FastAPI
* **Database:** PostgreSQL
* **Frontend:** React
* **ORM:** SQLAlchemy
* **Database Migrations:** Alembic
* **Version Control:** Git & GitHub

## Development Approach

Development will be done in stages:

1. Database Design
2. System Architecture
3. Backend Development
4. Frontend Development
5. Integration
6. Testing
7. Reports & Dashboard
8. Deployment

The project will prioritize a strong foundation and a connected system rather than developing each record as an isolated feature.

## Team

This project is being developed collaboratively by the AMAS FARM development team.
